# Roadmap

1. Independently curate and review official production packs from user-supplied official artifacts, beginning with one narrow exact domain rather than broad unverifiable coverage.
2. Add stable v1/beta Graph adapters, assignment/filter enrichment, cancellation progress, runtime-report adapters, and authorized live-tenant validation without write permissions.
3. Define an evidence-bearing organization-requirement rule schema and management/deviation lifecycle UI; free text must never become an automatic security judgment.
4. Expand documented parsers and diagnostics from real anonymized shape contracts while preserving unknown behavior.
5. Add full-result audit-history navigation and stronger operating-system credential storage while retaining privacy-off defaults.
6. Consider an explanation-only, opt-in, redacted AI summary after privacy/grounding validation; it may never create or modify findings.

The local 500-policy/10,000-setting smoke completed in 0.274 seconds for preview and 0.501 seconds for audit on the 2026-08-03 development device. Repeat the benchmark in CI and after parser/adapter expansion; add virtualization only when measurements justify it.

Every phase must remain runnable, update implementation status, and pass trust/security/cross-platform validation. This roadmap is intent, not a claim of implementation.
